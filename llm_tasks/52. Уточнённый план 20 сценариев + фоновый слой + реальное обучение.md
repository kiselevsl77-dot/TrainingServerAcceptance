# Уточнённый план: 20 сценариев + фоновый слой + реальное обучение

## Принятые допущения по вопросам 1, 3–6 (если возражений нет — работаю так)

- `acceptance/ml_samples.py` (новый): выбор модели/датасета, **выбор RAW только с ASCII-именем** (обход P0 лат.1), чтение сэмпла из RAW (`;`-CSV, последние 6 полей `U_A_signal…I_C_signal` = base64, 8192 симв.) — источник для `inference/single`; используется и сценариями, и предпросмотром.
- `acceptance/api.py`: `ModelsApi` собирается с `download_timeout` (как `FilesApi`).
- Тесты: `tests/unit/test_client_models.py` (fake transport, как у `test_datasets_api.py`), `test_ml_samples.py`.

## Шаг 4. Фоновая механика (остаток M1) — до тяжёлых
- `pult/jobs.py` (новый): `JobRunner` (поток на задание), состояние в памяти + персист в сессии (`counters["jobs"]`), результат пишется в сессию через существующие `execute_next`/`execute_call`, событие в журнал; `run_lock` удерживает фон (UI: «прогон идёт · фон»), синхронизация записи сессии/журнала между потоками.
- Маршруты: `GET /api/jobs`, `GET /api/jobs/{id}`, `POST /api/run` c `background: true` (или `action:"job"`).
- `$Задачи`-панель: наблюдения (`TaskMonitor.observed` уже в сессии), опрос, команды FSM (`pause/resume/interrupt`), привязка к проверке (`attach_to_check`).
- Параметры в карточке/панели ML: `epochs`, `batch_size`, `learning_rate`, `threshold`, сэмпл для `inference/single` (`sample_file_id`), «оставить/удалить артефакт»; `run_card.ML_FIELDS`, `server._ml_values/_missing_ml`, `view` (± подписи-метки).
- `acceptance/test_payloads.py`: предпросмотр `train/check/inference` с подстановкой; base64 в `inference/single` **маскируется**.
- Тесты: `test_pult_jobs.py` (запуск/прогресс/завершение/конкурентность), правки `test_pult_server.py`, `test_pult_view.py`, `test_run_card.py`, `test_test_payloads.py`.

## Главные риски, которые держу под контролем
1. Длительность/семантика `train` (создаёт ли новую модель по `trained_model_name`) — выясняю контрактным прогоном на шаге 5; до этого тяжёлые проверки не «зависают»: работают в фоне с ограничением `timeout` и вердиктом «не дошла до терминала».
