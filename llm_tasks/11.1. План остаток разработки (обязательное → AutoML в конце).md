## 3. Шаги 2–5 — T5…T8 (модульные блоки, по одной группе за шаг)

Общий каркас каждого шага (паттерн уже отработан на T3/T4 — повторяем без изобретений):

1. **Клиент** (`client/*.py`, схемы в `client/schemas.py`) — только то, чего нет.

4. **Экран** (`acceptance/ui/pages/<модуль>.py` + вкладка в `app.py`) и пикеры в чек-листе для новых id-параметров.
5. **Тесты**: `tests/unit/test_checks_<модуль>.py` (+ client-тесты, smoke-тест экрана).
6. **Документ этапа** + числа (`docs/02` §14 сводка, `README.md`, `catalog.py`/`checks.py`/`report.py` докстринги, `test_checks_catalog`/`test_checks_engine`/smoke KPI).
