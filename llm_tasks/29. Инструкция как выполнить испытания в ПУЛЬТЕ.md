# Инструкция: как выполнить испытания в ПУЛЬТЕ

## Кто что делает (роли)

| Роль                       | Зона ответственности                                         | Чего делать не может                                         |
| -------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **Руководитель испытаний** | планирование: наборы (`SCR-101`), программа с покрытием и объёмом (`SCR-102`), утверждение ревизий; критерии годности; чтение протокола и отчёта; подпись решения | **не запускает проверки** и не меняет результаты прогона     |
| **Инженер-испытатель**     | подготовка (сессия, стенд, снимки), прогон утверждённой программы, ручные отметки, снятие с причиной, замечания, уборка `__TEST__`, комплект отчёта | не меняет состав утверждённой программы — только новая ревизия у руководителя |

Комиссия/разработчик — только чтение. Разделение прав в коде пока не реализовано (задел `AR-P-8`), но последовательность шагов уже соответствует ролям.

## Общий маршрут: 5 групп меню = 5 шагов процесса

```
Планирование испытаний → Подготовка → Испытания → Результаты → Инструменты
 Ф0: что и в каком объёме   Ф0: сессия,  Ф1–Ф2: прогон  Ф2–Ф4: разбор,   служебное
                            стенд, снимок  «Следующая»   отчёт, решение
```

Гейты (из ТЗ): **G0** программа утверждена + стенд доступен + снимок «Начало»; **G1** все пункты выполнены или сняты; **G2** каждое расхождение — замечанием; **G3** нет открытых `P0/P1`; **G4** снимки сходятся, комплект полон, решение внесено.

**Минимальный путь, если нужно просто прогнать набор** (9 действий): `SCR-203` создать+начать сессию → `SCR-101` собрать/утвердить набор → `SCR-102` «🧩 Собрать программу (ИЛИ)» → «✅ Утвердить программу» → **«🧾 Собрать очередь прогона»** → `SCR-202` снимок «Начало» → `SCR-301` «▶ Следующая» / «▶▶ Пачка tech» → `SCR-302` отметка ручной проверки → `SCR-404` комплект и решение.

## Пять мест, где легко застрять (ровно то, на чём споткнулись вы)

1. **Очередь прогона** собирается отдельной кнопкой **в самом низу `SCR-102`** — после «Утвердить программу». Без неё на `SCR-301` команды запуска нет вовсе (экран показывает предупреждение). Это главный «неочевидный» шаг.
2. **Ручная проверка** останавливает «Пачку tech» и «Авто» — её закрывают отметкой на `SCR-302`.
3. **Снимок «Окончание»** — один из 7 пунктов полноты отчёта, а решение закрывает сессию: снимать снимок до «Зафиксировать решение».
4. **Статус замечания**: закрыть без комментария нельзя (правило ядра).
5. Экраны **`SCR-204` Данные стенда, `SCR-303` $Задачи, `SCR-405` Сравнение, `SCR-501` Инструменты** пока каркас — данных не показывают (этап 3 не закрыт), это не поломка.
