# 3. Что такое «сигнал» (для вопроса 4) — на живых данных

В комплексе слово «сигнал» означает **две разные вещи**, и путаница возникает именно здесь:

| Где                          | Что такое «сигнал»                                           | Документ                 |
| ---------------------------- | ------------------------------------------------------------ | ------------------------ |
| **В данных и при инференсе** | канал измерения: 6 каналов `U_A_signal … I_C_signal` (по `signal_length` = 2048 отсчётов, `signal_bytes` 3, `byte_order` Little, ADC-параметры `U_mult`/`I_mult`). Физика: напряжение/ток фаз A, B, C | 1.7 §3.6, табл. 5        |
| **В модели (`signals`)**     | «Связи **выходов модели с устройствами учёта**: для каждого выхода — список идентификаторов устройств из **справочника нагрузок**»; `signal_aliases` — «алиасы выходов: **номер выхода → человекочитаемое имя**». Число групп = `output_size` | 1.6 §4.2.5, 1.6 (create) |

Живой пример (снято сейчас с `stft_mlp-skfu-train-dev (trained)`, `output_size = 2`):

| Выход (`signal_num`) | Имя выхода (`signal_aliases`) | Привязанные устройства (`device_id` из `$Нагрузки`) и их категории |
| -------------------- | ----------------------------- | ------------------------------------------------------------ |
| 0                    | `miner`                       | `Antminer S19` (Номинальная нагрузка), `Antminer S19i` (Номинальная нагрузка), `Avalon_1240` (Выключение майнера), `Miner_3Ph` (отключение майнера) |
| 1                    | `not_miner`                   | `__OTHER__` (system, «Все остальное»)                        |

То есть «сигнал» в модели = **какие конкретные изделия (нагрузки) относятся к этому классу**. Отсюда практические требования: групп ровно `output_size` (иначе 400), `device_id` обязаны существовать в справочнике нагрузок (`GET /api/loads/list` — у пульта есть `client.loads.list_loads`).
