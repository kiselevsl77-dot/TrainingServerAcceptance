Ручной срез: «наборы → программа из 3 наборов с пересечением → утверждение → очередь
(состав = программе) → `▶ Следующая: TC-…` сценарием → маркер «последняя» → повтор →
прежний результат в истории → снятие с причиной (программа не изменилась) → возврат →
«Пачка tech» → шаг авто с остановкой на `live` → шаг «по вызовам» (журнал есть,
результата нет) → сохранение и восстановление сессии».
