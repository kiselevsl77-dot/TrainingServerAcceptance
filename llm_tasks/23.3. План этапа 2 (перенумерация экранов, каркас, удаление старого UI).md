Раздел = сотни, порядок в разделе = единицы (`SCR-\d{3}`), номера идут по порядку навигации.

(версия 1.2 документов), правило «ID неизменны» для требований `FR-P/DR-P/IR-P/AR-P/NFR-P/AC-P`

## 4. Гейты этапа

```
python -m pytest -q
python -m ruff check .
python -m ruff format --check .
python -m mypy acceptance tests
python -m tools.gen_endpoints --check
node --check mockup/*.js
```
Плюс смоук: все 15 экранов открываются (`streamlit.testing.v1.AppTest`), шапка показывает
состояние «нет сессии», событие `pult_started` попадает в журнал запуска.
Ручная проверка: `streamlit run acceptance/app.py` — 5 групп, 15 экранов, переключение
групп; `mockup/index.html` — hash-маршруты `#scr-101`, `#scr-301`.

«Живой вертикальный срез» (набор → программа → утверждение → «Следующая» → протокол) на
этапе 2 пройти нельзя — экраны пустые; он закрывается на этапе 3, начиная с `SCR-102`.

* не переписываем `docs/12` под новые экраны (этап 4) и не ведём `test_traceability.py`;
* не делаем справочник `docs/17` + `help/` (этап 5) и не перерабатываем отчёт («Программа
  и объём», `programme.csv`);

* не перенумеровываем исторические `llm_tasks/**`.
