## Что сделано

**Ядро объединения (новые модули):**
- `acceptance/records.py` — `Record` (`record_id = sha1(base|raw_id)[:12]`), `RecordsStats`, `RecordsOverview`, `build_records()`, `save_manifest()`. Правила: классификация файлов (`classify`), пары по имени + времени импорта (окно 1 ч → «подтверждено», иначе ⚠️ «не подтверждено»), версии/актуальность, кандидаты разметки, разметка без RAW, «прочие» файлы, манифест CSV/JSON + **контроль полноты** (`manifest_is_complete`: каждый файл ровно один раз как `raw_id`/`markup_id`/отдельная строка).

- `acceptance/ui/pages/records.py` — экран «Записи (RAW + markup)»: KPI, фильтры, вкладки **Записи / Дубли / Несопоставленные / Прочие файлы / Манифест**, карточки с обеими частями и кандидатами, выгрузка RAW/markup/пары-zip (крупные — с подтверждением), «в артефакты сессии», разбор разметки (записи/чанки), 4 ручных решения, замечания к API в 1 клик; HTTP-запросы помечаются метками `TC-REC-01…05`.

**Аддитивные правки:** `session.py` — схема **v2** (`artifacts[]`, `markup_stats{}`, чтение v1 без правок, `add_artifact`, `set_markup_stats`); `api.py` — снимок стенда дополнен показателями записей; `ui/state.py` — общий кэш реестра 60 с (`load_files`/`refresh_files`/`current_markup_stats`); `app.py` — пункт меню «🧩 Записи».
