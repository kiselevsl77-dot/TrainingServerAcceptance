## 2. Шаг 1.1 — клиент AutoML

1. **`client/schemas.py`** — новый раздел «ML models: AutoML (контракт 17.09.2026)», имена 1:1 с контрактом:
   - `MutationMode(scale/set/add)`, `RoundMode(int/nearest_pow2/none)`, `FindParamsLabel(normal/best/discarded/failed)`;
   - `MutationRuleCommon`, `MutationRangeRule` (`type: Literal["range"]`, `range: tuple[float,float]`), `MutationValuesRule` (`type: Literal["values"]`, `values: list[float|str]`, `random_choice=False`), дискриминированный `MutationRule = Annotated[MutationRangeRule | MutationValuesRule, Field(discriminator="type")]`;
   - `PopulationConfig` (`include_base_in_population: bool|None`, `rng_seed: int|None`, `rules: list[MutationRule] = Field(min_length=1)`);
   - `SortKey` (`metric`, `direction: asc|desc`, `tolerance`, `aggregate: sum|mean|max|min`), `SelectionConfig` (`best_count`, `discarded_count`, `sort_keys`);
   - `FindParamsPopulationCreateRequest` (`name` ≤200, `description`, `population_config`), `FindParamsPopulationCreateResponse` (`population_id`, `base_model_id`, `name`, `include_base_in_population`, `num_mutants`, `mutated_model_ids`);
   - `FindParamsPopulation` (`id`, `name`, `base_config`, `base_model_id|None`, `description|None`, `created_at`, `updated_at`), `FindParamsMutatedModel` (… `config_mutations`, `check_results`, `label|None`, `label_description|None`), `FindParamsSelection` (…, `dataset_id|None`, `check_dataset_id|None`, `train_config`, `test_config|None`);
   - `FindParamsSelectionRunRequest` (`train_dataset_id`, `test_dataset_id|None`, `train_config|None`, `test_config|None`, `selection_config|None`, `name|None`), `FindParamsSelectionRunResponse` (`task_id`, `runtime_id`, `population_id`, `message`).
   - Свободные `object` контракта (`base_config`, `config_mutations`, `check_results`, `train_config`/`test_config`) — `dict[str, Any]`, в докстрингах помечаются как замечание к API.
2. **`client/find_params.py`** (новый, зеркало `client/datasets.py`): `FindParamsApi.list_populations()`, `get_population(id)`, `delete_population(id)`, `create_population(model_id, *, name, population_config, description=None)`, `mutated_models(population_id, *, is_show_* = None, descending=None)`, `selections(population_id)`, `run_selection(population_id, *, train_dataset_id, test_dataset_id=None, train_config=None, test_config=None, selection_config=None, name=None)`, `grid_csv(population_id, *, selection_id=None)` → **`bytes` + content-type** (первый не-JSON медиатип). Локальный `_drop_empty`; докстринг-шапка со списком эндпоинтов и блоком «замечания к API» (нет операции создания популяции «одним вызовом» `POST /api/ml_models/find_params/population`, свободные `object`, каскадный `DELETE` без предпросмотра).
3. **`acceptance/api.py`**: поле `find_params: FindParamsApi` в `Apis` + сборка в `build()`. В `take_stand_snapshot` AutoML **не добавляется** (независимость: агрегаты стенда и отчёта считаются без него).
4. **`acceptance/checks/runner.py`**: `AUTOMATION_DOMAINS += "acceptance.checks.automl"`, хелпер `AutomationContext.find_params_api()` (рядом с `loads_api()`/`files_api()`), импорт `FindParamsApi` в `TYPE_CHECKING`.

6. **`acceptance/ui/pages/console.py`**:

   - `grid.csv`: проверить/доправить `_save_result_artifact` (расширение `.csv` при `spec.is_csv`) и отображение — «файл: … байт, `text/csv`» уже поддержано `ExchangeResult.body_preview`.

## 4. Шаг 1.3 — группа `TC-AUTO` (8 проверок)

## 6. Решения и компромиссы (рекомендации)

1. **Этап `T11`** для `TC-AUTO`: сохраняет список этапов стабильным, честно кодирует «независимый блок после T10». Альтернатива «без этапа» потребует менять `GroupPlan` и UI-сортировку — не рекомендую.
2. **`TC-AUTO-02` — 422-проба** (тело без `name`) вместо POST с несуществующим `model_id`: детерминированно, гарантированно не создаёт сущностей, остаётся классом `tech`.
3. **«Недоступно в сборке» = «пропущена»**, не «блокировано API»: не порождает автозамечание в `session.notes`, не влияет на статусы чужих групп (в отчёте — пометка в вердикте/`note`).
4. **Перенумерация `docs/02` §14→§15, §15→§16** — цена за вставку раздела группы; затрагивает ссылки в `catalog.py`, `docs/05`, `docs/09`, `test_checks_catalog` (проверю грепом все упоминания «§14»/«§15»).
5. **AutoML вне снимка стенда и агрегатов отчёта** — прямая реализация п. 5 независимости.
6. **`grid.csv` — артефакт**: если `_save_result_artifact` даёт `.txt`, поправлю выбор расширения по `is_csv` (это единственная правка консоли вне пикеров).
