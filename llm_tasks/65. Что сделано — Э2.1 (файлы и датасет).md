# 65. Что сделано — Э2.1 «Реальная тренировка» (файлы и датасет)

План этапа — `llm_tasks/64`. Ниже — фактические результаты, а не намерения.

## Что теперь работает в пульте

| Действие оператора | Что происходит | Маршрут |
|---|---|---|
| Выбрал CSV и нажал «⬆ Загрузить на стенд» | файл уходит на стенд **потоком** (тело запроса — сам файл, не JSON/multipart), пульт показывает прогресс, считает размер и `sha256`; имя проверяется по правилу §9 | `POST /api/data/files?file_name=…&file_type=RAW` |
| Смотрит «Загружено в этой сессии» | таблица: файл, роль (измерения/разметка), размер, `sha256`, время, `file_id` стенда | `GET /api/train` (`data.uploads`) |
| «➕ Создать датасет» | `POST /api/datasets/` с именем `__TEST__…`, датасет сразу выбирается в профиль сессии | `POST /api/datasets` (`create`) |
| «⇪ Наполнить файлами» | в `fill` уходят `file_id` загруженных файлов (измерения + разметка); факт «что отправлено» фиксируется **до** вызова, потому что стенд не возвращает ни состав, ни `task_id` | `POST /api/datasets` (`fill`) |
| «✔ Проверен вне пульта» | отметка `dataset_validated_at` + паспорт сборки (какие файлы, размеры, `sha256`, кто собрал) | `POST /api/datasets` (`validate`) |
| «↻ Перечитать состав» | состав перечитывается с учётом стенда (режим `auto`), результат ложится в учёт сессии | `POST /api/datasets` (`refresh`) |
| Смотрит карточку данных | метаданные датасета, паспорт сборки, состав, список файлов паспорта | `GET /api/datasets/{id}` |

Задача `dataset-fill` ищется в реестре `$Задач` по идентификатору датасета; если воркер её
не разбирает (дефект стенда, тот же, что у `training`), экран честно пишет «задача наполнения
не видна», а не «выполнено».

## Изменения в коде

| Файл | Что сделано |

| `client/files.py` | `upload(..., path=…)`: `httpx` стримит файл с диска; приём `content=bytes` сохранён (сценарии проверок `TC-FILE-*` не изменились) |

| `pult/view.py` | блок `data` в `train_view`: загруженное, датасеты, паспорт сборки, состав, статусы шагов; шаг «Данные» больше не «этап Э2», а живой статус |
| `pult/web/index.html`, `app.js` | зона «Данные (датасет)»: загрузка с прогрессом (`XHR`), таблицы, кнопки датасета, паспорт сборки, пояснение границы «валидация вне пульта» |
| `README.md`, `docs/12` §28.2–28.5 | 33 маршрута, схема v10, новый модуль, правило «файлы идут потоком», Э2 перенесён из «запланировано» в «работает» |
