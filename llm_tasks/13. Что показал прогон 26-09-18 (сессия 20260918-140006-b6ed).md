# 2. Две находки, которые стоит поправить в пульте

1. **`POST /api/data/file` не требует заполнить `file_type`.** В консоли это свободное поле `Тип файла (file_type)` без пометки обязательности, отправка не блокируется → вы получили 422 при первом заходе. По контракту обязательны `file` **и** `file_type`. Правка: пометить `*`, блокировать отправку при пустом поле, дать `selectbox` (`RAW` / `LOADS` / `ONNX`) с подсказкой из спецификации.
2. **Пикер задач в чек-листе показывает только задачи, поставленные на наблюдение в сессии** (`_render_task_picker` → `monitor.observed(session)`). Из-за этого `TC-TASK-03/06` «пропущены» (в группе на момент прогона наблюдений было 0), а на стенде 14 задач. Правка (T5/T9): дать в пикере выбор из серверного списка задач — как уже сделано в консоли (`_task_picker`), либо автоподстановку первой подходящей.

1. Диагностика → `celery-test`, длительность **60–120 с** → запустить.
2. «⏱️ Наблюдение» → включить наблюдение (интервал 2 с) → дождаться статуса **«Выполняется»** (running).
