# Документы испытаний (копия постановки)

В этом каталоге — копия документов из постановки основного проекта
(`TrainingServerUI/context/01. Постановка/05. Задача тестового стенда как отдельного проекта/`,
а также спецификация `SOM1.json` и замечания `SOM1. Комментарии.md` из
`TrainingServerUI/context/01. Постановка/`), чтобы комплект испытаний был
самодостаточен при передаче заказчику. Обновление копии:

```powershell
python -m tools.sync_docs
```

| Документ | Содержание |
|---|---|
| `01. ТЗ на пульт испытаний (временный UI).md` | задание: терминология (запись / дубль / субдатасет), три блока требований к API (актуальное / минимальные доработки / перспективные), архитектура изолированного проекта, FR-T1…FR-T11, NFR-T1…NFR-T7, критерии приёмки, этапы T0…T10, риски |
| `02. Чек-лист испытаний.md` | программа проверок `TC-*` (69 проверок): классы `tech`/`live`/`heavy`/`manual`, статусы, правила выполнения, трассировка на UC/FR/BR/FSM, ожидаемо блокированные проверки |
| `03. Этап T1 — записи.md` | отчёт об этапе T1: состав работ, правила объединения, живые показатели реестра (265 файлов / 129 записей, 128 в дублях, 108 с не-ASCII именами), результаты тестов, дефекты API |
| `04. Этап T2 — консоль и замечания.md` | отчёт об этапе T2: генератор реестра 32 операций из `SOM1.json`, движок вызовов консоли, правила подтверждений (NFR-T4) и карточка запуска, экраны «Консоль запросов» и «Замечания к API», схема сессии v3, результаты тестов и подтверждённые дефекты API |
| `SOM1.json` | OpenAPI-спецификация испытуемого сервера — **источник** реестра эндпоинтов консоли (`python -m tools.gen_endpoints`) |
| `SOM1. Комментарии.md` | описание API, нестыковки и предложения (P0/P1/P2), §5 «Классификация требований к API», §6 «Находки этапа T2», фактические показатели живого реестра |
| `README.md` проекта (уровнем выше) | как запускать пульт, что реализовано на этапах T0–T2, переменные окружения, журналирование |
| `VENDOR.md`, `BACKPORT.md` | происхождение вендорной копии `client/`/`lib/` и план обратного порта наработок в основной UI |

Дополнения к сводке замечаний к API ведутся в основном репозитории
(`context/01. Постановка/SOM1. Комментарии.md`) и копируются сюда командой
`python -m tools.sync_docs`.
