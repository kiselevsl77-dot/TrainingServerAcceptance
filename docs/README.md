# Документы испытаний (копия постановки)

В этом каталоге — копия документов из постановки основного проекта
(`TrainingServerUI/context/01. Постановка/05. Задача тестового стенда как отдельного проекта/`,
а также спецификация `SOM1.json` и замечания `SOM1. Комментарии.md` из
`TrainingServerUI/context/01. Постановка/`), чтобы комплект испытаний был
самодостаточен при передаче заказчику. Обновление копии:

```powershell
python -m tools.sync_docs
```

Разбор изменений, закрытые и открытые замечания к API и план приведения пульта в
соответствие — в документе `09. Контракт API 17.09.2026 — изменения и план работ.md`.
Актуальность контракта проверяется тестом `tests/unit/test_contract_version.py`
(размер, SHA-256, состав, блок AutoML, снятое требование фазы), а команда
`python -m tools.sync_docs` **не перезаписывает** контракт без явного флага
(`--with-contract`) — чтобы более старая версия из постановки не откатила актуальную.
